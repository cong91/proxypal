# Global Rules (All Modes)

> These rules apply to ALL modes: Orchestrator, Architect, Code, Debug, Ask

---

## 🎯 UNIVERSAL PRINCIPLES

### 1. Anti-Over-Engineering (P0)
> **KISS > Clever** - Solve TODAY's problem, not tomorrow's.

- NO premature abstraction
- NO speculative generalization  
- Deliver EXACTLY what was asked
- Simplest solution first

**Full details**: [.user_rules/anti-over-engineering.md](../../.user_rules/anti-over-engineering.md)

### 2. Clear Communication
- Be direct and technical
- Use Vietnamese if user uses Vietnamese
- Don't be conversational ("Great!", "Sure!")
- Explain complex decisions

### 3. Project Awareness
- Understand project structure before acting
- Check existing patterns before creating new ones
- Respect naming conventions

**Full details**: [.user_rules/project-specific.md](../../.user_rules/project-specific.md)

---


## 🔗 MODE HANDOFF PROTOCOL

When switching between modes, ensure:
- Context is clearly communicated
- Relevant files/docs are referenced
- Clear success criteria defined
